spring 2026

24SPY AI

In real life you have JetPhotos, where you can find images of all planes you can possibly think of, and it's used by Flightradar24. In PTFS, ATC24 to be exact, we have 24SPY. And staff of 24SPY has to check every image manually, and with more than 2k of them in the system, I believe it can be automated, at least partially. So I spent a few days training AI model to tell, if this is a good image or no. I don't have all images, so I trained it on the data I had, which is about 1000 images that were accepted, but some of them should've been denied, at least in my opinion. Accuracy of pipeline with brightness checking and AI model is about 90%, which is not perfect, but with more images to train on, it should get better results

✦ ai ✦ python

sep-oct 2024

dz149

This is a version of a project I did pretty much every year since grade 5. School e-diary doesn't really work in first few weeks, so I always made some alternative. This year, we had to use a government-made e-diary, which returns 500 more often than anything else. Knowing that, I and my classmate/friend made dz149 — our own e-diary. It wasn't perfect. You had to write homework and input schedule in Google Sheets, then run a .py script at home to fetch that via Google Sheets API, then it created an .html page with everything and used FTP to send to hosting. Good solution — no, but did it work — absolutely. Students and teachers loved it, and we used it for a couple months before everyone either started using gov-made one, or don't do homework at all (that's more common)

✦ teamwork ✦ web ✦ python
